# Isaac ecosystem resources

## NVIDIA resources and community skills

- [Isaac Sim MCP Server](https://docs.isaacsim.omniverse.nvidia.com/latest/development_tools/isaac_sim_mcp.html)
  and [source](https://github.com/NVIDIA-Omniverse/kit-usd-agents/tree/main/source/mcp/isaacsim_mcp):
  searches Isaac Sim documentation and code; it does not control a running simulator.
- [Isaac Lab skills](https://github.com/isaac-sim/IsaacLab/tree/main/skills) and
  [Isaac Sim skills](https://github.com/isaac-sim/IsaacSim/tree/release/6.3/skills): upstream
  guidance on environments, training, physics, assets, sensors, ROS and migration. See
  [our skill guide](AGENT-SKILLS.md#nvidias-skills) for how to use them with isaac-mcp.
- [Official Kit and USD agent tools](https://github.com/NVIDIA-Omniverse/kit-usd-agents).
