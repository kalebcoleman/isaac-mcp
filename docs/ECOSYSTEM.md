# Isaac Sim and Isaac Lab MCP ecosystem, by capability

Every tool defined by other Isaac Sim, Isaac Lab and Omniverse MCP servers, grouped by what it
does and compared with what isaac-mcp offers today, to decide what is worth building. The same
tools listed repository by repository are in [ECOSYSTEM-BY-REPO.md](ECOSYSTEM-BY-REPO.md).
Generated by [`scripts/ecosystem_catalog.py`](../scripts/ecosystem_catalog.py) on 2026-11-01 from
24 repositories (578 tools, 481 distinct names); rerun it to refresh.

How to read this page:

- **Areas** come from name rules in
  [`scripts/ecosystem_capabilities.py`](../scripts/ecosystem_capabilities.py); a misfiled tool
  is fixed there. Tools from isaac-mcp's own upstreams (`inbarajaldrin/isaac-sim-mcp`, `inbarajaldrin/omni-kit-mcp`) are left out.
- **isaac-mcp today**: *Have* means a named tool exists; *Partial* means only for the UR5e twin
  or part of the area; *run_python only* means an agent can do it by writing Kit Python;
  *Missing* means neither.
- **isaac-mcp today** includes the `sim__*` and `assets__*` pack added by PR #11
  (`exts/sim-tools`, documented in TOOLS-SCENE.md).
- **Planned** names a milestone (M1–M7) in
  [plans/SIM-TOOLS-FOLLOWUP.md](plans/SIM-TOOLS-FOLLOWUP.md); `—` means nothing is planned yet.
- **Priority** is a judgement for a robot-agnostic sim and training server: *High* = build
  next, *Medium* = worth it after that, *Low* = only for specific projects, *Skip* = do not
  rebuild, *Done* = covered.
- In the tables, tools with the same name in several repositories share one row; the
  description and source link come from the first repository listed.
- **Tools are extracted statically.** The generator parses each repository's Python with `ast`
  and lists functions decorated as MCP tools, `ToolDefinition(...)` calls, `*TOOL_REGISTRY`
  dicts and NeMo Agent Toolkit function configs. Nothing was installed or run, so a listed tool
  is one the code defines, not one that was seen working. Tools built dynamically, in other
  languages, or in test folders are not listed.
- **Descriptions are the authors' own words** (first paragraph of the docstring or description,
  shortened), including those written in Chinese. Neither they nor the summaries are an
  endorsement.
- **Source links are pinned** to the commit that was read, with the line where the tool is
  declared.

## What to build next

Areas marked *High* or *Medium*, with the repositories that implement the most tools in each (worth reading before writing your own).

- **[Create, edit and arrange prims](#create-edit-and-arrange-prims)** (High; isaac-mcp: Partial). Moving and adding physics to any prim (imports and the user's own USD) is planned; layout helpers (grid, scatter, align) are optional. Planned: any prim, typed attributes, revert (M5). Best references: [mateuszbestai](https://github.com/mateuszbestai/nvidia-omniverse-isaacsim-mcp-server) (14), [Tim0320/IsaacSim-MCP](https://github.com/Tim0320/IsaacSim-MCP) (6), [krngrover6](https://github.com/krngrover6/omni-mcp) (6).
- **[Assets, robots and environments](#assets-robots-and-environments)** (High; isaac-mcp: Partial). A browsable robot library and MJCF import are what remain. whats2000's curated library and serionist's `create_robot` are good references. Planned: NVIDIA cloud library, bundled samples, MJCF (M6). Best references: [Tim0320/IsaacSim-MCP](https://github.com/Tim0320/IsaacSim-MCP) (12), [whats2000](https://github.com/whats2000/isaacsim-mcp-server) (9), [mateuszbestai](https://github.com/mateuszbestai/nvidia-omniverse-isaacsim-mcp-server) (8).
- **[Robot state and joint control](#robot-state-and-joint-control)** (High; isaac-mcp: Partial). Name-based targets and a settle-and-measure move are what agents steer with. GenRobo/isaac-sim-mcp has the clearest named-joint API. Planned: names, velocities, clamping, runtime gains, move-until-settled (M4). Best references: [GenRobo](https://github.com/GenRobo/isaac-sim-mcp) (9), [Tim0320/IsaacSim-MCP](https://github.com/Tim0320/IsaacSim-MCP) (7), [Milokucia](https://github.com/Milokucia/dex-isaac-mcp) (5).
- **[Stage files, layers and variants](#stage-files-layers-and-variants)** (Medium; isaac-mcp: Partial). Open, sublayers, references and variant selection are common and easy to get subtly wrong by hand (anonymous stages, edit targets). Planned: —. Best references: [Tim0320/IsaacSim-MCP](https://github.com/Tim0320/IsaacSim-MCP) (9), [serionist](https://github.com/serionist/omniverse-mcp) (7), [mateuszbestai](https://github.com/mateuszbestai/nvidia-omniverse-isaacsim-mcp-server) (5).
- **[Scene inspection and measurement](#scene-inspection-and-measurement)** (Medium; isaac-mcp: Have). World bounds, distances and mesh statistics (`get_prim_bounds`, `measure_distance`, `get_mesh_stats`) are the remaining gap. Planned: bounds, distances, camera list (M1). Best references: [mateuszbestai](https://github.com/mateuszbestai/nvidia-omniverse-isaacsim-mcp-server) (6), [krngrover6](https://github.com/krngrover6/omni-mcp) (5), [serionist](https://github.com/serionist/omniverse-mcp) (5).
- **[Physics setup and queries](#physics-setup-and-queries)** (Medium; isaac-mcp: Partial). Scene queries (raycast, overlap, contacts) and `apply_force` are the remaining gap. Planned: raycast, contacts (M3); physics on any prim (M5). Best references: [Tim0320/IsaacSim-MCP](https://github.com/Tim0320/IsaacSim-MCP) (12), [mateuszbestai](https://github.com/mateuszbestai/nvidia-omniverse-isaacsim-mcp-server) (8), [nullbyte91](https://github.com/nullbyte91/nvidia-isaac-mcp) (3).
- **[Robot tuning experiments](#robot-tuning-experiments)** (Medium; isaac-mcp: Missing). dex-isaac-mcp only: range tests, tracking error, parameter sweeps that restore the original value. Cheap to add once joint control exists, and gives agents numbers. Planned: tracking error in `sim.joints.move` (M4). Best references: [Milokucia](https://github.com/Milokucia/dex-isaac-mcp) (6).
- **[Grippers, IK, trajectories and skills](#grippers-ik-trajectories-and-skills)** (Medium; isaac-mcp: Missing). Tim0320/IsaacSim-MCP has bounded Lula IK, trajectory jobs, grippers and mobile bases; worth studying if agents should move robots without ROS. Planned: —. Best references: [Tim0320/IsaacSim-MCP](https://github.com/Tim0320/IsaacSim-MCP) (14), [ros-claw/simscene](https://github.com/ros-claw/simscene) (4).
- **[Viewport capture and recording](#viewport-capture-and-recording)** (Medium; isaac-mcp: Have). Headless viewport recording from the pack and multi-angle prim views (serionist `inspect_prim`) would make results visible without a desktop. Planned: Kit viewport screenshot and MP4 (M7). Best references: [Milokucia](https://github.com/Milokucia/dex-isaac-mcp) (9), [serionist](https://github.com/serionist/omniverse-mcp) (7), [ros-claw/simscene](https://github.com/ros-claw/simscene) (4).
- **[ROS 2 and OmniGraph](#ros-2-and-omnigraph)** (Medium; isaac-mcp: Partial). Generic Clock / TF / JointState / camera publishers and Action Graph editing (Tim0320/IsaacSim-MCP) would cover other robots. Planned: —. Best references: [Tim0320/IsaacSim-MCP](https://github.com/Tim0320/IsaacSim-MCP) (24), [whats2000](https://github.com/whats2000/isaacsim-mcp-server) (2).
- **[Logs and diagnostics](#logs-and-diagnostics)** (Medium; isaac-mcp: Partial). A cursor and a since-now summary turn the tail into a debugging loop; never hook Kit's logging from Python (two servers deadlocked Kit that way). Planned: filters, cursor, summary (M2). Best references: [GenRobo](https://github.com/GenRobo/isaac-sim-mcp) (1), [Tim0320/IsaacSim-MCP](https://github.com/Tim0320/IsaacSim-MCP) (1), [chloepilonv](https://github.com/chloepilonv/mcp-server-isaaclab) (1).
- **[Isaac Lab training and evaluation](#isaac-lab-training-and-evaluation)** (Medium; isaac-mcp: Have). Missing: interactive env sessions (create, step, observe, reset) from chloepilonv/mcp-server-isaaclab, video listing, and a GPU status read. Planned: —. Best references: [chloepilonv](https://github.com/chloepilonv/mcp-server-isaaclab) (16), [Tim0320/IsaacLab-MCP](https://github.com/Tim0320/IsaacLab-MCP) (9), [Milokucia](https://github.com/Milokucia/dex-isaac-mcp) (7).
